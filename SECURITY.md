# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately on GitHub instead: [Report a vulnerability](https://github.com/Techdom-Digital-Solutions-U-limited/shashura-mobile-money-for-CampTix/security/advisories/new), also under this repository's Security tab.

Include the plugin, CampTix, WordPress and PHP versions, the steps to reproduce it, and what someone could do with it. Use sandbox credentials and test phone numbers in your report, never real API keys or customer details.

If the problem is in the Shashura API or merchant dashboard rather than this plugin, contact Shashura support through the dashboard at [shashura.com](https://shashura.com).

## Supported versions

Security fixes go into the latest release, so please check the problem still happens there before reporting.
